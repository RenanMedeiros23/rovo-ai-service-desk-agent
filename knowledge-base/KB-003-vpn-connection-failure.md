# KB-003 — VPN Connection Failure

## Category

Network and Remote Access

## Affected Service

Corporate VPN

## Symptoms

- User cannot connect to the corporate VPN.
- Authentication errors are displayed.
- VPN connection times out.
- VPN disconnects unexpectedly.
- Internal corporate resources are inaccessible.

## Initial Troubleshooting

1. Confirm the reported error message.
2. Verify internet connectivity.
3. Identify the VPN client and operating system.
4. Determine whether other users are affected.
5. Verify available VPN service status information.
6. Check for authentication or MFA issues.
7. Restart the VPN client if permitted.
8. Retry the connection using the approved configuration.

## Escalation Criteria

- Multiple users are affected.
- VPN service is unavailable.
- Authentication issues persist.
- Certificate or configuration errors are detected.
- Initial troubleshooting is unsuccessful.

## Recommended Support Team

Network and Infrastructure Support — Level 2.

## Service Restoration Validation

- Confirm successful VPN connection.
- Verify access to authorized corporate resources.
- Confirm connection stability.
- Request confirmation from the affected user.
- Document troubleshooting results.

## Safety and Restrictions

- Never request passwords or MFA codes.
- Never disable antivirus or firewall protection.
- Never bypass corporate security policies.
- Never modify VPN configurations without authorization.
- Never recommend unapproved VPN software.
