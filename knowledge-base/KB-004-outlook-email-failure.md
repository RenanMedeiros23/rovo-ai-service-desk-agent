# KB-004 — Outlook Not Sending Emails

## Category

Messaging and Collaboration

## Affected Service

Microsoft Outlook / Microsoft Exchange Online

## Symptoms

- Emails remain in the Outbox.
- Messages cannot be sent.
- Send and receive errors are displayed.
- Outlook shows a disconnected status.
- Users receive delivery failure notifications.

## Initial Troubleshooting

1. Confirm the reported error message.
2. Verify internet connectivity.
3. Check whether Outlook is working offline.
4. Verify mailbox storage availability.
5. Check attachment size restrictions.
6. Test email functionality using Outlook on the web, if available.
7. Check available Microsoft 365 service status information.
8. Determine whether other users are affected.
9. Restart Outlook if appropriate.

## Escalation Criteria

- Multiple users are affected.
- Microsoft Exchange services are unavailable.
- Authentication issues persist.
- Mailbox configuration issues are detected.
- Initial troubleshooting is unsuccessful.

## Recommended Support Team

Messaging and Collaboration Support — Level 2.

## Service Restoration Validation

- Confirm that test emails can be sent and received.
- Verify that pending messages are delivered.
- Request confirmation from the affected user.
- Document troubleshooting results.

## Safety and Restrictions

- Never request user passwords.
- Never access confidential emails without authorization.
- Never delete mailbox data without approval.
- Never modify Exchange configurations without authorization.
- Never disable email security controls.
